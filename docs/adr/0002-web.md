# ADR 0002: Web: Next.js on Vercel (Frankfurt)

**Status:** Accepted · **Date:** 11 Nov 2026

## Context
Finder pages must load fast on slow phones with no app; the website, owner web dashboard and payment webhooks also need hosting. Selasey already runs a portfolio on Vercel.

## Options
| Option | For | Against |
|---|---|---|
| Next.js on Vercel | Server-rendered finder pages (fast first load); React and TypeScript shared with the app; API route handlers for webhooks; functions can run in the Frankfurt region (fra1); familiar hosting. | Vercel is US-based; personal data must stay in the database (EU), not in Vercel logs. |
| Astro or SvelteKit on Cloudflare | Very light pages; edge hosting. | Less code shared with the React Native app. |
| Single-page app | Simple. | Slow first load on weak connections; fails the finder speed requirement. |

## Decision
Use Next.js (App Router) on Vercel with server functions pinned to fra1. Finder pages server-rendered, minimal JavaScript.

## Consequences
Meets the finder speed target and shares code. Logging must exclude personal data.
